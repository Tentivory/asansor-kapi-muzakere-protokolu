# Asansör Kapı Müzakere Protokolü (AKMP-7)

> **Resmi statü:** Bu depo bir yazılım değildir. Bir bekleme holüdür. Hol de sizi bekler.

Asansör kapısı kapanmayı reddettiğinde çoğu insan düğmeye basar. Biz basmayız. Biz **dilekçe** yazarız.

AKMP-7, katlar arası diplomasiyi standartlaştıran dünyanın ilk (ve muhtemelen son) protokolüdür. Kapı bir taraftır. Siz diğer tarafsınız. İkisi de haklıdır. İkisi de geç kalmıştır.

## Neden var?

Çünkü bir gün 3. katta kapı, “kapanırsam kimse beni özlemez” dedi. Mühendis gülmedi. Hukukçu gülmedi. Sadece çay ocağındaki kupa güldü ve o gün bugündür bu repo ayakta.

Patates ile ilgisi yoktur. Patates başka bir bakanlığındır. Biz kapı bakanlığıyız.

## Kurulum

```bash
git clone https://github.com/Tentivory/asansor-kapi-muzakere-protokolu.git
cd asansor-kapi-muzakere-protokolu
python3 asansor.py
```

Bağımlılık yoktur. Ruh hali vardır. Ruh hali `requirements.txt` dosyasına sığmaz, o yüzden dosya boş değil, kırgındır.

## Kullanım

```bash
python3 asansor.py --kat 7 --gerekce "toplantıya geç kalırsam sunum slaytı intikam alır"
python3 asansor.py --demo
python3 asansor.py --gizli
```

`--gizli` ek protokolü açar. README bunu anlatmaz. README da bir tür kapıdır.

## Protokol maddeleri

1. Kapıya “kapan” denmez. “Kapanmayı değerlendirmeniz arz olunur” denir.
2. Her iç çekiş bir ret oyudur.
3. Üç retten sonra kapı komisyon kurar. Komisyon çay ister.
4. Çay gelmezse kapı yarım kapanır. Buna **stratejik aralık** denir.
5. Stratejik aralıktan geçen kişi diplomat sayılır, yolcu değil.

## Çıktı örneği

```text
AKMP-7 OTURUM TUTANAĞI
kat: 7
karar: KAPALI (isteksiz)
gerekçe: dilekçe usulüne uygun, kapı duygusal olarak hazır değil ama evrak tamam
```
